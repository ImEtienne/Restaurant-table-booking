# ZinoBlog Dashboard

Dashboard administratif pour ZinoBlog - Site statique

## 🚀 Installation

Installez les dépendances :

```bash
npm install
```

## 📦 Utilisation

### Lancer le serveur de développement

```bash
npm run dev
```

ou

```bash
npm start
```

Le site sera accessible sur `http://localhost:3000` et s'ouvrira automatiquement dans votre navigateur.

### Options disponibles

- `npm run dev` - Lance le serveur avec rechargement automatique
- `npm start` - Même chose que `npm run dev`
- `npm run serve` - Lance le serveur sans ouvrir automatiquement le navigateur

## ✨ Fonctionnalités

- Dashboard avec statistiques
- Gestion des utilisateurs
- Mode sombre/clair
- Menu latéral avec sous-menus
- Interface responsive

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (via CDN)
- Live Server (développement)
